# Board

Mirror of the GitHub board columns. GitHub Projects boards can't be created from
the cloud session (the Projects API needs GraphQL, which is blocked here), so this file is the board.
To make the real board: GitHub → your profile → Projects → New project → Board, name it
"Study Workspace", add columns Backlog / In Progress / Review / Done, then "Add items" →
search `repo:shack-dev-j/study-workspace` and add all issues.

"Review" means: built and tested, waiting in a pull request. "Done" means merged into main.
