# Roadmap

Milestones are built in this order. Each one ends with a push and a project
zip to test on Arch Linux. Issue lists: `docs/ISSUES.md`, status:
`docs/BOARD.md`.

| # | Milestone | Issues | Result |
| --- | --- | --- | --- |
| M1 | Core app + Arch desktop app | #1–#13 | Server, safe data layer, backups, export/restore, app shell, launcher with own window, icon, install/uninstall, PKGBUILD, notifications |
| M2 | Study trackers + Library & files | #14–#29 | Subjects, homework + attachments, library + PDF reader + bookmarks, past papers, time log, timetable, habits, SAT, portfolio |
| M3 | Applications | #30–#37 | Universities (from the research report), scholarships, documents, deadlines, activities, essays, Plan A / B |
| M4 | Cyber / ICO | #38–#43 | ICO research, topic map, study plan, TryHackMe, practice challenges, writeups |
| M5 | Dashboard & weekly review | #44–#46 | Today screen, weekly review charts, Ctrl+K search |
| M6 | Polish & QA | #47–#49 | Responsive + keyboard pass, full QA, README / CLAUDE.md / HANDOFF.md |
